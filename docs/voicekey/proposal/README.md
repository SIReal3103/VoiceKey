# VoiceKey Proposal Documentation

VoiceKey is a proposed USB-C companion and Android app for short, face-to-face English ↔ Vietnamese conversations. The phone provides the display and local AI processing; the accessory is designed to provide Push-to-Talk, a visible recording state, and close-use microphones.

## Start Here

1. Read [the technical proposal](voicekey-technical-proposal.md) for the problem, solution, hardware concept, AI design, cost plan, and pilot gates.
2. Use `research/` to review papers, platform constraints, commercial products, pricing, and public demo sources.
3. Use `reports/` to see the evidence checks, assumptions, and remaining proof required before a product claim or formal submission.

## What This Documentation Does—and Does Not—Claim

The documentation supports a research-backed product direction. It does not claim that a VoiceKey prototype has already achieved a particular latency, accuracy, battery life, microphone advantage, USB reliability, or commercial release status. Those outcomes require measurements on the named phones and prototype, plus licensing review for every shipped model and voice.

Public social and video links are included to show adjacent product formats and workflows. They are not proof of VoiceKey performance.
